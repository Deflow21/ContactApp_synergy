# ContactApp

**ContactApp** — это приложение для управления контактами, написанное на Python с использованием PyQt5. Оно позволяет добавлять, редактировать и удалять контакты, а также просматривать их детали.

## Установка

1. **Клонируйте репозиторий**:
git clone https://github.com/Deflow21/ContactApp.git
cd ContactApp


2. **Запустите приложение**:
После установки зависимостей вы можете запустить приложение с помощью следующей команды:
python -m ContactAppUI.contacts_app

ИЛИ просто скачать exe и установить приложение на компьютер
