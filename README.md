# ContactApp

**ContactApp** — это приложение для управления контактами, написанное на Python с использованием PyQt5. Оно позволяет добавлять, редактировать и удалять контакты, а также просматривать их детали.

## Установка

1. **Клонируйте репозиторий**:
git clone https://github.com/<USERNAME>/ContactApp.git
cd ContactApp


2. **Установите зависимости**:
Убедитесь, что у вас установлен Python (рекомендуется версия 3.6 или выше) и pip. Затем выполните следующую команду для установки необходимых библиотек:
pip install -r requirements.txt


3. **Запустите приложение**:
После установки зависимостей вы можете запустить приложение с помощью следующей команды:
python -m ContactAppUI.contacts_app
